# 验证与版本

- v60 在原厂菜单同时显示闲置关机和睡眠定时。两项可见及本地播放已验证，各种超时组合仍需独立记录。
- v70 用实机同一首歌验证了实时 EQ、保存和播放连续性。v72 的三平台 DAC 验收属于基础播放与暂停恢复。
- v74 用同目录同名 WAV/LRC 验证歌词同步。播放目录中长按右键进入 v80 的歌曲操作菜单。删除是可恢复移动，目标为同卷 `.c10-recycle`，恢复时移回原目录并去掉 `.deleted` 后缀。目录重启后重建。
- v84 在本地播放时读到 `filter=fast id=72 control=40 value=b0`。v86 的对照试听缺少切换日志，因此保留快滤波作为已验证基线。
- v76 双播放器队列实验已撤回。可编辑队列、M3U 和机内 FM 独立收音未作为本仓库交付功能。
