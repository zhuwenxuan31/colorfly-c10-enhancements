# Colorfly C10 Enhancements

七彩虹 C10 原厂 Linux 播放器的社区改进项目。保留原厂界面、MPlayer 和机内 CS4398 音频通路。欢迎提交测试记录、修复和新功能。

| 功能 | 版本 | 验证状态 |
| --- | --- | --- |
| 闲置关机与睡眠定时 | v60 | 实机确认两项同时可见，本地播放正常 |
| 十段实时 EQ | v70 | 实机确认同曲调整生效、播放连续、设置可保存 |
| USB DAC 兼容修复 | v72 | Mac、iPhone 16 Pro、掌阅 Tango2 基础播放与暂停恢复实测通过。Mac 枚举为 16 bit／48 kHz 双声道 |
| 同步歌词 | v74 | 实机确认同名 UTF-8 LRC 与测试 WAV 同步，声音正常 |
| 原厂目录长按右键删除（播放键） | v80 | 测试曲成功移入同卷回收目录，读回哈希一致 |
| CS4398 滤波只读诊断 | v84 | 实机读到原厂快滚降，芯片 ID 为 `0x72` |
| CS4398 快慢滤波试听 | v86 | 离线测试通过，实机缺少切换回执，听感结论待验证 |

## 开发与测试

运行 `sh tools/check-host.sh`，可在 macOS 或 Linux 上验证定时、USB 音频、歌词、EQ、删除手势、回收目录和 DAC 诊断等主机测试。需要 C11 编译器和 Python 3。

[构建与回退](docs/build.md) · [验证记录和版本说明](docs/validation.md) · [贡献指南](CONTRIBUTING.md)

本仓库是面向原厂固件的源码项目。发布内容包含补丁、测试和维护文档。原厂固件由设备所有者自行准备。
